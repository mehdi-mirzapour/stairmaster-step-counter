🚀 Quickstart & Developer CLI Guide

Setup instructions and command reference to run all step-counting pipelines locally in seconds.

1. Installation

# Clone repository
git clone https://github.com/username/stairmaster-step-counter.git
cd stairmaster-step-counter

# Install with Astral uv (recommended):
uv sync

2. Unified CLI Commands

Run Local Benchmark

Compares all local edge models and prints a rich telemetry table:

uv run stairmaster --benchmark

Run Solution 2 with Telemetry HUD Video

Generates a real-time annotated MP4 video with sports telemetry dashboard and face anonymization:

uv run stairmaster --solution 2 --duration 5.0 --save-video

Run Solution 3 (Sub-Millisecond Machine Step Tracker)

Tracks physical revolving stair treads:

uv run stairmaster --solution 3 --duration 5.0 --save-video

3. CLI Flag Reference

Option Type Default Description
--benchmark Flag False Run multi-solution benchmark comparison
--solution String 2 Pipeline: 1 (VLM), 2 (Pose), 3 (Kymograph), 4 (Fusion), 5 (Audio)
--duration Float 5.0 Duration to analyze in seconds
--save-video Flag False Generate broadcast HUD annotated video
--video Path None Custom input video file path
